# Course Catalog

A course catalog project built for the Advanced Web Technologies course.

## Technologies

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- App Router

## Features

- Home page
- About page
- Course list
- Dynamic course pages
- Server Components
- Client Component for likes
- Dynamic routes with `generateStaticParams`
- Loading UI
- Not-found page
- Shared navigation

## Routes

- `/`
- `/about`
- `/courses`
- `/courses/[id]`
